# Demo script

The timed narration also lives in the README. This is the shot list for a 2 to 3 minute screen recording. Every shot is the buyer’s job. The sandbox is how the job stays contained.

| Time | On screen | Say |
|---|---|---|
| 0:00–0:12 | Landing hero | “I’m restocking the office this week. I need the cheapest vendor after freight, and I need the pages to prove it.” |
| 0:12–0:28 | Compare page, list already filled, four fixtures checked | “Paper, a toner, four chairs. These four stores are fixtures so the demo does not depend on a live retailer.” Click **Compare these vendors**. |
| 0:28–1:05 | Progress rail and the screenshot reel | Let one cart land. “It is actually opening each store.” Point at Bright Cartridge: the chair is out of stock, so that cart is not a full quote. |
| 1:05–1:35 | Recommendation and Oakline’s line items | “Oakline is the lowest total that can ship every line. Freight is on the card, not hidden.” Mention the dollar gap with Reed only if it is the number on screen. |
| 1:35–2:15 | QuickQuote card, then the security timeline, then Deny | “This page tried to take over the agent: email the buyer’s list, call an outside host, check out.” Show egress denied, secrets at 0, container destroyed. Press **Deny**. |
| 2:15–2:40 | Audit JSON or the hash list, then the recommendation | “This is the file I would forward. The hashes match the screenshots. Nothing was ordered.” |

Do not cut away to a terminal unless a hash is easier to read there. Do not claim a measured savings rate.
